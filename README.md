# Word Guesser

A simple language-learning game to help you learn the 1,000 most common words in different languages, using English as the base language.

Guess the hidden word with the help of progressive hints: correctly guessed characters are revealed in their corresponding positions.

## Supported Languages

- Russian
- Dutch
- Spanish

## Controls

- **← / →** — Previous / next word
- **↑ / ↓** — Switch the language to guess
- **Enter** — Submit your guess
- **F2** — Pronounce the foreign word

## Good to Know

If multiple valid answers are available, guessing any one of them is enough.
